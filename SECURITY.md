# Security Policy

Goalie is a research prototype that invokes coding agents and runs repository checks. Read the detailed [safety model and limitations](docs/security.md) before using it on valuable or confidential repositories.

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/zeuzmakessoftware/goalie/security/advisories/new). Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Please do not open a public issue for an unpatched vulnerability.

We will acknowledge a report as soon as practical, investigate it, and coordinate disclosure after a fix or mitigation is available.

## Supported versions

Until the project publishes a stable release line, only the latest commit on `main` receives security fixes.
